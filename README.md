form0-connector-sqlite is a database connector that integrates with the [form0 open-source ecosystem](https://form0.dev) to automatically store form submissions in SQLite databases. It implements a hybrid storage approach, extracting common fields into dedicated columns for fast querying while preserving the complete form data as JSONB.
